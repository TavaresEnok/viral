Design system

Guia de implementação do redesign. Direção: dark-first, lime elétrico + magenta, tipografia pesada, copy de creator. Tudo aqui mapeia direto para os tokens do globals.css e tailwind.config.ts existentes.

01 · Cores

Lime é a única cor de ação — todo botão primário, score e estado ativo. Magenta aparece apenas em gradientes de progresso e acentos raros. Nunca os dois competindo no mesmo componente.

05 · Migração do código

Os nomes de token do globals.css são mantidos — só os valores mudam. O Tailwind continua funcionando sem refatorar classes.

/* :root — tema escuro */
--bg-base: #0C0C11;    /* era #0A0A0A */
--bg-surface: #14141B; /* era #111111 */
--bg-elevated: #1C1C26;
--hairline-subtle: #26262F; --hairline-strong: #37373F;
--ink-primary: #F4F4F6; --ink-secondary: #A6A6B2; --ink-tertiary: #6E6E7A;
--accent: #C8F542;     /* era teal #14B8A6 — texto sobre accent agora é #10120A */
--accent-hover: #D6FF55;
--accent-glow: rgba(200,245,66,.20);
--signal-special: #FF4FA3; /* novo: gradientes de progresso */

/* tailwind.config.ts → fontFamily */
sans: ['Instrument Sans', …]  /* era Inter */
display: ['Bricolage Grotesque', …]  /* novo — títulos */
mono: ['Spline Sans Mono', …]  /* era JetBrains Mono */

/* regras de forma */
botões/chips: border-radius 999px · cards: 18–20px · inputs: 14px
botão primário: h-46px · bg-accent · text-#10120A · font-bold

Checklist de implementação: ① trocar valores no globals.css → ② trocar fonts no layout.tsx (next/font) → ③ Button.tsx: pill + texto escuro no primário → ④ renomear labels da sidebar → ⑤ aplicar Bricolage nos headings (classe font-display).
